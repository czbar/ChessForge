Code Signing Steps

Having installed Certum's middleware.
Make sure it is connected (run SimplySign desktop and enter the token).

1. cd C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64
2. signtool sign /sha1 "9d9fcd76c897263b875cdcd2fe14eb670ab27404" /tr http://time.certum.pl /td sha256 /fd sha256 /v "C:\GitHub\ChessForge\SetupChessForge\Release\ChessForge.msi"

(Previously this worked too
   2. signtool sign /tr http://timestamp.certum.pl /td SHA256 /fd SHA256 /a "C:\GitHub\ChessForge\SetupChessForge\Release\ChessForge.msi"
)

3. Generate token on the SimplySign app on the phone
